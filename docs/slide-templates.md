# Slide templates and session flow

Every CODED Juniors session is a 90-minute deck that runs **Start → Teach → Build → Close**, following the house method: Hook → Context → Build → Share → Reflect, and the feeling Wonder → Creation → Pride. Each slide component below is one 1920×1080 layout; its folder holds `slide.html` (the Slides-format source) and a README.

## Deck flows

**Camp day (Summer, Winter, B2B camps).** Room cover → room rules → Activity Title → Today You Will → Ice Breaker (optional) → [Question → Definition → Fun Fact] × 2–4 → How?! → Tool Reveal → How to Use AI → Activity Time → Step Screenshots → Challenge → Show & Tell → What Did We Learn → Thanks. Day 2 opens with Where Did We Stop + Recap Stars.

**Weekend program (Fri + Sat).** No rooms and no rules slide. Program Cover (Day 1 – Day 2) → Activity Title → Ice Breaker + rounds → content as above → Coming Up Next → Thanks. Day 2 opens: Program Cover (Day 2 tile highlighted) → Title → Ice Breaker → Where Did We Stop → Recap Stars.

**Partner session (3 hours).** As the camp day, plus Break Time in the middle and Game Time near the end.

**Two-day activities** follow Day 1 = Designing, Day 2 = Coding/Printing, with Step numbering carried across the days.

## Slide counts and timing

Day 1 decks run 45–65 slides, Day 2 decks 35–60. Count about 15 short dividers and reveals. The timings in the speaker notes must add up to the slot (lab 75–90 min, zone 45–60 min, weekend 90 min).
