# KeywordHeading

The signature emphasis: one to three key words per sentence coloured red, blue, then amber; yellow on red slides.

- Colour **1–3 key words** per sentence (nouns and verbs), in the order `keyword-1` red → `keyword-2` blue → `keyword-3` amber; connecting words stay `ink`.
- Headings: one coloured keyword only.
- On red: key words in `yellow-on-red`; the first word of a divider in `lavender-on-red`.
- Amber, yellow and lavender only at display sizes (44px+ bold).
