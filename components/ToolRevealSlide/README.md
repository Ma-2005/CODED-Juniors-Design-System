# ToolRevealSlide

The tool reveal "Using… [Tool Name]!" with the tool's logo on the white half.

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `tool`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: revealing the tool of the day (Gemini, Meshy, Tynker, Delightex, Bambu Studio, Tinkercad, Suno…).
- HOW: tool logos are in the Asset Library, folder "10 Tool & App Logos". Use the tool's logo only where you talk about that tool.
- SAY: We will use [Tool]. [What it does in one line].
- TIME: 15 seconds.

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
