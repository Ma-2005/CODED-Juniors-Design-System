# CodeyPoses

Codey, the CODED Juniors robot, in the pose that matches each slide's job.

- One Codey per slide, big (500–800px on a slide), on the red side of a hero or split slide.
- Pose by job: laptop = cover · hands on hips = activity title · bursting wall = Ice Breaker · running = You Are a… · thinking = every question · lightbulb = Fun Fact · kneeling = Challenge · jumping = Game Time · lemonade = Break · hello bubble = Show & Tell · reading = What Did We Learn · waving = Coming Up Next.
- More poses (VR headset, 3D printer, Sphero, hard hat, hacker hoodie…): the Mascot group and the CODED Juniors Asset Library.
