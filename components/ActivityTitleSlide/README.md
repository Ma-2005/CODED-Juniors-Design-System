# ActivityTitleSlide

The activity title on red: the activity name and "Day 1: [Day Name]" in yellow, with Codey standing proud.

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `title`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: the activity title, right after the cover (weekend) or the room rules (camp).
- HOW: activity name on two lines if it is long. Day line = "Day 1: Design Day", "Day 2: Coding Day", and so on.
- SAY: Today is [Day Name]! Today you will [one-line promise].
- TIME: 30 seconds.

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
