# GameTimeSlide

Game Time (Blooket, Kahoot) with the website pill and Codey jumping.

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `game`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: a class quiz game (Blooket, Kahoot) as a recap or while something prints/loads.
- HOW: put the game name and website. Never put the game PIN on the slide; show it live from the game screen.
- TIP: turn on random names for young kids, and read the questions with kids who cannot read yet.
- TIME: [10 to 15] minutes.

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
