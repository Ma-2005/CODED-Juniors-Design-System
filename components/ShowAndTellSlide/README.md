# ShowAndTellSlide

Show & Tell with a sentence frame, so every kid can share.

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `showtell`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: the Share step (the PRIDE beat). Never cut it, even when the build runs long.
- HOW: give a sentence frame so every kid can speak. Shy kids can share with their mentor instead.
- DO: Each kid shows their project for about 30 seconds. Name one design choice out loud for each kid ("[Galaxy style] with that glow is a great choice!").
- TIME: 10 minutes.

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
