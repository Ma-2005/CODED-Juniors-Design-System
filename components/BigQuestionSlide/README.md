# BigQuestionSlide

The question that comes before every definition, with Codey thinking.

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `question`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: the question that comes BEFORE every new idea (question first, definition second).
- OTHER QUESTIONS: "What is a [Robot]?", "Where do you see [AI] today?", "How do WE speak to computers?", "Have you ever…?"
- ASK: What do you think [topic] means? Take 3 or 4 answers. Every answer is welcome.
- TIME: 1 minute.

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
