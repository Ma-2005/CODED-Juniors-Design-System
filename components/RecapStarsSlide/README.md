# RecapStarsSlide

Recap Stars: five questions, five stars, answers pop in on click.

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `stars`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: the recap quiz at the start of Day 2 (the Stars Board, 0/5 to 5/5).
- HOW: five words from last session. Each green answer pops in on click: the class wins a star.
- ASK each question. Accept any answer that is close, and cheer every star!
- TIME: 3 minutes.

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
