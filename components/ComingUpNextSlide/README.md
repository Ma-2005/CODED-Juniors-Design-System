# ComingUpNextSlide

The teaser for the next session, split with Codey waving.

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `next`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: the teaser before the thanks slide, so kids leave wanting more.
- HOW: one exciting sentence about next time, plus one thing to think about at home.
- SAY: Next time you will [teaser]. Think about [your filament colour / your game idea]!
- TIME: 1 minute.

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
