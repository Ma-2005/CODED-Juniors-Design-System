# CreditsSlide

"Credits are like Coins! Careful not to OVER use them." with the try limit.

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `credits`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: any AI tool with a credit limit (Meshy, Higgsfield, Vidu, Suno…).
- HOW: set the try limit in the pill.
- SAY: Every [result] costs credits, like coins in a game. You get [one try and one retry], so check your work before you press Generate!
- TIME: 1 minute.

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
