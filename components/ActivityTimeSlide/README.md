# ActivityTimeSlide

The "Activity / Time!" divider with clouds, a star and the Super Coder badge.

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `activity`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: the start of every hands-on block. Variants: "Challenge Time!", "Mission Time!", "LIVE DEMO Time!", "TESTING TIME!", "EXTRA Time!" (change the lavender word).
- HOW: keep the subtitle short (under about 30 characters) so it stays on one line.
- SAY: Now it's YOUR turn! Let's [activity].
- TIME: [total minutes for the whole activity block].

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
