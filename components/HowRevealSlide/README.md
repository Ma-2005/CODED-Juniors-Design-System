# HowRevealSlide

The suspense slide "How?!" before a tool reveal, with the pink 3D question mark.

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `how`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: the 15-second suspense slide right before a tool reveal ("How?!" → "Using Google Gemini!").
- ASK: So how do we [make it]? Which tool do you think we will use?
- TIME: 15 seconds.

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
