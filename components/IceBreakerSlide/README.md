# IceBreakerSlide

The Ice Breaker divider: game name, how to answer, and Codey bursting through a wall.

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `icebreaker`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: the ice-breaker divider, before the first game round.
- GAME IDEAS (from past Juniors decks): Spot the Difference, 2D or 3D?, AI or Not AI?, Which Image is AI?, Guess the Character, Guess the Game, Guess the App, Wordle, Connections, Would You Rather?
- HOW: write how kids answer in the first pill (e.g. "Raise your hand!") and the number of rounds in the second.
- TIME: 5 to 7 minutes for the whole game.

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
