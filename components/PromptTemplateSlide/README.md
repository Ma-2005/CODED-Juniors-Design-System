# PromptTemplateSlide

"Let's Get Writing!": a fill-in prompt in a red dashed box with coloured [BLANKS].

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `prompt`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: a fill-in-the-blank prompt template (the Juniors bracket style).
- HOW: write the full prompt with 2 to 4 coloured [BLANKS]. Younger kids change only the blanks; older kids may add details. Post the prompt in Google Classroom before class so kids can copy and paste it.
- SAY: Copy the prompt, then change only the coloured words.
- TIME: 2 minutes.

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
