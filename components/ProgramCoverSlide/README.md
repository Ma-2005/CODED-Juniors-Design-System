# ProgramCoverSlide

The program cover for weekend and partner programs: program name, type pill and Day 1 / Day 2 date tiles, with Codey at his laptop.

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `cover`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: the first slide of a weekend or partner program (both days in one deck). Camps use the room cover instead.
- HOW: replace every [bracket]. Keep the two date tiles; highlight today's tile with a yellow border on Day 2. Swap Codey for a pose that matches the program.
- SAY: Welcome to [Program Name]! Today is Day [1], [Friday].
- TIME: 30 seconds.

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
