# BreakTimeSlide

"BREAK Time! Let's Relax and Continue Later!" with Codey and his lemonade.

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `break`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: a break in sessions of 2 hours or more (partner sessions, weekends).
- BREAK GAME IDEAS: Speed Typer on monkeytype, a quick Kahoot, or free time.
- SAY: Great work! Take a [10]-minute break. We start again at [time].
- TIME: [10] minutes.

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
