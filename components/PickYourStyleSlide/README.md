# PickYourStyleSlide

A 4×2 choice grid of picture tiles: styles, themes, characters.

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `pick`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: a choice menu with picture examples: styles, themes, characters, colours, game ideas.
- HOW: put one example picture in each grey box (make them before class). Delete a row if you only need 4 options.
- ASK: Which [style] will you pick? You can also invent your own!
- TIME: 1 minute.

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
