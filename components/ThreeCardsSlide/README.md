# ThreeCardsSlide

A definition in three numbered cards (red, blue, amber).

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `threecards`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: a definition with three parts. Example (the Juniors AI definition): 1 Machines that Learn, Create, and Help us · 2 Not Magic, just Trained with Data · 3 Used in Phones, Apps, and Games.
- HOW: keep each card to about 8 words. For 4 points use the Rules slide layout instead.
- TIME: 1 to 2 minutes.

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
