# WhatDidWeLearnSlide

The reflection: "What Did We Learn Today?" and "Which Part did you Enjoy the Most?".

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `learned`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: the reflection at the end of EVERY session (most old decks were missing it).
- HOW: 3 or 4 words from today, plus the enjoy question. Swap the icons to match each word.
- ASK each question and let kids answer out loud. No writing.
- TIME: 3 minutes.

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
