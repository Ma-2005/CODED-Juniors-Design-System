# FunFactSlide

"FUN Fact! Did you KNOW?" with Codey's lightbulb idea.

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `funfact`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: a fun fact or tip between ideas. Juniors classics: "Did you know that we can PROMPT to make things?", "Did you know that there are multiple ways to code?", "The coolest AI creations are not made in one try!"
- SAY: Did you know that [fact]?
- TIME: 30 seconds.

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
