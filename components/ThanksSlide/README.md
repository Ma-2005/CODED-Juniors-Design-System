# ThanksSlide

The closing "THANKS! Have Fun Coding!" with the Arabic value stickers.

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `thanks`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: the last slide of every session, with the Arabic value stickers (إبتكار · برمجة · بطل · بطلة · وناسة · إبداع).
- HOW: "Have Fun Coding!" for coding sessions, "Have Fun Innovating!" for design and girls programs.
- SAY: Great job today, [designers]! See you [tomorrow / next time]!

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
