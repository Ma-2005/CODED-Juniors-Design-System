# LogoLockup

The logo rules: the solo CODED Juniors logo, the partner lockup (CODED Juniors | KFH) and the Winter Camp logo.

- **No partner:** `juniors-logo-red` on content-white, `juniors-logo-white` on red, 203×80px, 72px from the edge, 44px from the top.
- **Partner program:** the lockup image (CODED Juniors, divider, partner), 439×64px, 52px from the top. Colour version on light, white version on red.
- **Winter Camp only:** `juniors-logo-winter`.
- Top-right on most slides; top-left on covers and split slides whose right half is red. Never tilted, animated, recoloured or covered.
