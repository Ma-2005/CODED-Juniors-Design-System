# TodayYouWillSlide

The kid-facing goal of the day in one sentence with three coloured keywords, beside a photo of the finished product.

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `today`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: the kid-facing goal of the day. Every deck needs one.
- HOW: one sentence, three coloured key words (verb, product, tool). Show a photo of a finished example on the right, and pass a real one around if you have it.
- SAY: This is what you will make today. [Short description].
- TIME: 1 minute.

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
