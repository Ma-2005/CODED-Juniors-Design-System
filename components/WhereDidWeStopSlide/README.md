# WhereDidWeStopSlide

The Day 2 recap: three steps done and today's step in a red card.

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `recap`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: the start of Day 2 (or any next session): what we did last time, and the step we do today (the red card).
- ASK: What did we do last time? Then [step 1], then [step 2], then [step 3].
- SAY: And today is step 4: [today's step]!
- TIME: 2 minutes.

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
