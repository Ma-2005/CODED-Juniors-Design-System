# FourRulesSlide

Four rule cards with 3D icons: safety, care, roles or tips.

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `rules`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: four rules or tips: tool safety (hot nozzle, hands away), robot care, team roles, competition rules, "4 things to check".
- HOW: 2-word rule title, then a short reason. Swap the 3D icons for ones that match each rule.
- ASK: Which rule is the most important? Why?
- TIME: 1 to 2 minutes.

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
