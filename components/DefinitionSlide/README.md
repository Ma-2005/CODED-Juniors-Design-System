# DefinitionSlide

The split definition slide: "What is [X]?" and a 3D icon on red, the one-line definition with coloured keywords on white.

A full 1920×1080 slide layout in the CODED Juniors camp-deck style. Copy it from the **CODED Juniors Slide Template** deck (slide id `definition`), or take `slide.html` in this folder (Slides format) and copy the pictures it uses into your deck as assets: in this repo the image paths point to the `assets/` folder.

**Logo.** Shown with the solo CODED Juniors logo (203×80). For a partner program swap in the partner lockup (439×64, `lockup-juniors-kfh-*`): see Logos and partners in the README.

## How to use it

- USE FOR: the definition that answers the question slide. The most-used layout in Juniors decks.
- HOW: one sentence, 2 or 3 coloured key words (blue, amber, red). Add an analogy (filament = ink, block coding = building blocks, variable = treasure chest). Swap the 3D icon on the left for one that fits.
- SAY: [Topic] means [definition]. It's like [analogy].
- TIME: 1 minute.

Replace every [bracket] with real lesson content. Keep the layout, sizes and colours; change the words, the 3D icon and the Codey pose only when the slide's job changes.
