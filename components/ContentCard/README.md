# ContentCard

The white card: 32px corners, soft shadow, a 3D icon, a coloured title and a short line.

- `card-white`, `radius-card` (32px), `shadow-card`, 32–64px padding.
- A 3D icon (190–260px on a slide), a 48px coloured title, a 38–40px `ink-muted` line.
- Cards in a row share one width; 40–80px gaps.
