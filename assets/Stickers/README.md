# Stickers

Arabic value stickers and badges. Place them tilted (−8° to +6°), with a soft shadow, never over text.

**On the THANKS! slide (white on red):** `sticker-ibtikar-white-blue.png` إبتكار (innovation), `sticker-barmaja-white-blue.png` برمجة (coding), `tag-batal-yellow.png` بطل (hero), `tag-batala-yellow.png` بطلة (heroine), `tag-ibdaa-yellow.png` إبداع (creativity), `tag-wanasa-blue.png` وناسة (fun). Use five or six together, each at a different tilt.

**Badges:** `badge-super-coder-blue.png` (Activity Time, rewards), `badge-super-coder.png`, `sticker-pro-staff.png` (staff only).

**Older red stickers:** `sticker-wanasa*.png`, `sticker-ibdaa*.png`, `sticker-abtal.png` أبطال, `sticker-batal.png`, `sticker-batala.png`, `sticker-barmaja-*.png`: one per slide on social posts and BSK-style slides.

More colourways are in the CODED Juniors Asset Library, folder 02 Arabic Stickers & Badges. Don't edit the originals; for a new word, make a new sticker in the same shape.
