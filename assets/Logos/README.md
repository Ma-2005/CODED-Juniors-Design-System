# Logos

Never recolour, redraw, tilt or animate these marks.

**Which logo (the rule):**
- **No partner** → `juniors-logo-white.png` on juniors-red, `juniors-logo-red.png` on content-white or white. 203×80px on slides, 72px from the edge, 44px from the top.
- **Partner program** (KFH Baiti, KFH-sponsored Girls Camp) → the lockup: `lockup-juniors-kfh-white.png` on red, `lockup-juniors-kfh-color.png` on light. 439×64px, 52px from the top. One image: CODED Juniors, a thin divider, KFH. Don't add a separate CODED box logo.
- **Winter Camp only** → `juniors-logo-winter.png` (the logo with snow). `juniors-badge-red.png` is a smaller copy of it.

**The files:**
- `juniors-logo-red.png` / `juniors-logo-white.png`: the official winged CODED Juniors logo (608×240).
- `lockup-juniors-kfh-color.png` / `lockup-juniors-kfh-white.png`: CODED Juniors | KFH partner lockup (2057×300).
- `kfh-logo-green.png` / `kfh-logo-white.png`: the current KFH (Kuwait Finance House) star logo alone, for documents. Never use the old KFH logo.
- `juniors-banner-blue.png`: the blue CODED JUNIORS tape strip, a playful sticker.
- `coded-juniors-white.png`: all-white Juniors lockup.
- `coded-wordmark-white.png` / `coded-wordmark-navy.png`: the CODED Academy wordmark, for CODED-level materials.
- `coded-favicon-navy.png`, `coded-favicon-light.png`: the CODED "C" mark for app icons.
- `bsk-logo.png`: the BSK school crest, BSK materials only (they use the BSK Program system).

Partner and tool logos (KNET, Boubyan, Senan, Gemini, Meshy, Tinkercad…) are in the CODED Juniors Asset Library; use one only where that partner or tool is involved.
