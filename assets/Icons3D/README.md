# Icons3D

Glossy clay-style 3D icons: the only illustration style. One or two per slide, big (190–400px on a 1920 slide, 116px beside list lines), sometimes tilted. Never flat clip-art, never emoji.

**Topics:** `icon-ai` / `icon-ai-bulb` (AI), `icon-ai-prompt` (prompting), `icon-ai-rocket` (AI tools), `icon-vibe-code` (vibe coding), `icon-code-red`, `icon-code-badge`, `icon-code-phone` (apps), `icon-code-monitor` (coding), `icon-python` / `icon-python-red`, `icon-controller` (games), `icon-vr`, `icon-3d-screen`, `icon-3d-printer`, `icon-laptop-blue`, `icon-board`, `icon-puzzle-red`, `icon-magnet`, `icon-cyber-shield` (cyber safety), `icon-rocket`.

**Rules and recaps:** `icon-lightning` (energy, quick tip), `icon-finger-one` (one idea, rule 1), `icon-check-cross` (right or wrong, check), `icon-treasure-chest` (variables, credits).

**Decoration:** `icon-sparkles`, `icon-sparkle-stars`, `icon-star-gold`, `icon-sun`, `icon-snowflake` (Winter Camp), `icon-backpack` (back to school).

About 200 more 3D icons are in the CODED Juniors Asset Library, folder 06 3D Icons.
