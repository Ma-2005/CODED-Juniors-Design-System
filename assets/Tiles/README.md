# Tiles

Deck objects from the recap and title slides.

- `tile-barmaja` (برمجة), `tile-ibtikar` (إبتكار), `tile-wanasa` (وناسة): cream rounded topic tiles with a 3D object and an Arabic value word. Show three in a row on red, each at a different tilt, ~260px tall at 1920.
- `tile-add-smile`: a red block-coding block reading "add smile", for block-coding lessons.
- `tile-window`: the white "WINTER CAMP" wordmark with the mascot, for red winter-camp covers.
